0. 한눈에 보는 전체 흐름

한 시험지를 처리하는 순서는 이렇습니다. 한 학교씩 차례대로 합니다.

1
PDF 올리기 — 작업 화면에서 학교 칸에 시험지 PDF를 올립니다. (자동으로 글자·수식을 읽어 한글 파일을 만듭니다)
2
검수하기 — 만들어진 결과를 원본 PDF와 비교하며 문제마다 "맞음 / 고침"을 표시합니다.
3
제출 · 다운로드 — 검수 완료를 누르면 2단 한글(HWPX) 파일이 나옵니다. 그걸 받아 타이핑 마무리에 씁니다.
💡 컴퓨터가 시험지를 100% 완벽히 읽지는 못합니다. 검수가 품질을 좌우합니다 — 천천히 정확히 봐주세요.

1. 로그인 · 작업 화면

  • 주소로 접속해 구글 계정으로 로그인합니다. (권한이 없다면 관리자에게 등록을 요청하세요.)
  • 로그인하면 작업 화면(매트릭스)이 나옵니다. 위쪽에서 연도와 과목 탭을 고릅니다.
  • 아래에 학교 목록이 줄지어 있고, 각 학교 줄에서 변환 단계(PDF → 검수전 → 검수완 …)를 볼 수 있습니다.

2. PDF 올려서 변환하기

1
위에서 연도·과목을 먼저 선택합니다. (파일 이름이 이걸로 정해집니다)
2
해당 학교 줄에서 📄 PDF 업로드 를 누르고 시험지 PDF를 선택합니다. (또는 파일을 그 줄에 끌어다 놓기)
3
변환 중 표시가 돌아갑니다. 끝나면 변환완료가 됩니다. (보통 1~2분)
4
변환이 끝나면 그 학교 줄에서 검수하기 를 눌러 검수 화면으로 들어갑니다.
💡 사진이 옆으로 누운 시험지여도 자동으로 똑바로 돌려서 처리합니다. 그냥 올리시면 됩니다.
⚠️ 같은 PDF를 또 올리면 변환이 다시 돌아가니, 한 번만 올립니다. 잘못 올렸으면 검수 화면 위쪽 삭제 후 다시 올리세요.

3. 검수하기 (가장 중요)

화면 보는 법

  • 왼쪽: 원본 시험지 이미지 (페이지 탭으로 넘기고, +/− 로 확대)
  • 오른쪽: 컴퓨터가 읽은 문제들이 카드로 한 개씩 나옵니다.
  • 왼쪽 원본과 오른쪽 글자가 같은지 문제마다 비교합니다.

문제마다 두 가지 중 하나를 누릅니다

①
✓ 정확 — 원본과 똑같으면 누릅니다. (잘못 눌렀으면 다시 누르면 풀립니다)
②
✎ 수정 / 오류 — 틀린 곳이 있으면 누릅니다. 편집 칸이 열립니다.

"수정"을 누르면 — ⚠️ 여기가 핵심

편집 칸에 두 곳이 있습니다. 반드시 구분하세요.
✅ 올바른 내용여기 글자를 고치면 최종 한글 파일에 반영됩니다. 실제 고칠 내용을 여기에 적습니다.
📝 오류 메모관리자 기록용 메모일 뿐, 본문은 바뀌지 않습니다. "여기 틀림" 같은 설명만 적는 칸입니다.

즉 "집합기호 없음" 처럼 메모만 적으면 결과물은 안 고쳐집니다. 실제로 고치려면 "올바른 내용" 칸에서 글자를 바로잡아야 합니다.

③
고쳤으면 반영 을 누릅니다. 카드가 "수정됨"으로 바뀝니다.

다 봤으면 제출

  • 모든 문제를 ✓정확 또는 ✎수정 처리한 뒤, 맨 아래 검수 완료 → HWPX 재생성 을 누릅니다.
  • 완료되면 다운로드 링크가 뜹니다. 그 한글 파일을 받아 마무리 작업에 씁니다.
💡 메모만 적고 본문을 안 고쳤으면, 제출할 때 "메모만 있고 본문이 안 고쳐졌다"는 경고가 뜹니다. 한 번 더 확인하세요.

4. 수식을 몰라도 고치는 법

수식(LaTeX)을 몰라도 됩니다. "수정"을 열면 위에 수식 기호 버튼판이 있습니다.

1
분류 탭을 고릅니다 — 집합 · 분수·지수 · 부등호 · 그리스 · 도형 · 함수
2
고칠 자리에 커서를 두고, 넣고 싶은 기호 버튼을 클릭하면 그 자리에 들어갑니다. (예: 집합 탭의 U ∩ ∪, 조건제시 {x|…})
3
아래 미리보기에 실제 보이는 수식 모양이 나옵니다. 제대로 들어갔는지 눈으로 확인하고 반영.
💡 분수는 분수 a/b, 루트는 √, 제곱은 x² 버튼을 누르면 됩니다. 직접 타이핑할 필요 없습니다.

5. 🔴 확인 필요 처리

컴퓨터가 못 읽은 자리는 🔴 확인 필요 표시로 남습니다. (예: 흐릿한 집합기호)

  • 그 문제 카드에 🔴 확인 필요 N곳 칩이 보입니다.
  • 원본 PDF를 보고 그 자리에 무엇이 들어가야 하는지 확인합니다.
  • "수정" → "올바른 내용" 칸에서 【★ 확인 필요】 글자를 지우고, 기호 버튼으로 알맞은 내용을 채웁니다.
⚠️ 만약 채우지 않고 제출하면, 최종 한글 파일에 빨간 글자로 【★ 확인 필요】 가 남습니다. 빨간 글자는 "사람이 채워야 할 곳"이라는 뜻이니, 가능하면 검수에서 다 채워주세요.

6. 그림 검수 (그림이 있을 때)

그림이 있는 시험지는 작업 화면 학교 줄에 🖼 검수 N건 배지가 뜹니다.

1
배지를 클릭하면 그림 검수 화면이 열립니다.
2
문제마다 왼쪽 빨간 박스(자동으로 잡은 그림 영역)를 봅니다. 맞으면 자동 선택.
3
박스가 틀리면 오른쪽 그림에서 마우스로 올바른 영역을 드래그한 뒤 수동 영역 적용. 그림이 아니면 건너뛰기.
4
다 했으면 위쪽 HWPX 반영 을 누릅니다. 검수한 그림이 한글 파일에 들어갑니다.

7. 자주 하는 실수 · 주의

메모만 적었는데 결과가 안 고쳐져요"오류 메모"는 기록용입니다. 실제로 고치려면 "올바른 내용" 칸에서 글자를 바꿔야 합니다. (3장 참고)
수식을 어떻게 입력하죠?타이핑 말고 기호 버튼판을 쓰세요. 미리보기로 확인. (4장)
빨간 【★ 확인 필요】가 뭐예요?컴퓨터가 못 읽은 자리입니다. 원본 보고 채워주세요. (5장)
"정확"을 잘못 눌렀어요그 버튼을 다시 누르면 풀립니다.
변환이 안 끝나요 / 오류가 떠요잠시 기다려도 그대로면 관리자에게 알려주세요. 화면의 오류 메시지를 함께 전달하면 좋습니다.
결과 한글 파일은 어디 있죠?검수 완료 후 나오는 다운로드 링크, 또는 작업 화면 학교 줄의 다운로드 버튼. (구글 드라이브 AKP 폴더에도 자동 저장됨)
💡 막히면 언제든 관리자에게 물어보세요. 이 설명서는 위쪽 🖨 인쇄 로 종이로도 뽑을 수 있습니다.
