0. 한눈에 보는 전체 흐름

매트릭스에서 학교 선택 → PDF 업로드 → 회전 확인 → AI 분석 → 검수(문제·그림) → 한글파일 생성 → 드라이브 자동 저장

한 시험지는 이 순서로 한 화면 안에서 끝납니다. 위쪽 단계 표시 (① 업로드 → ② 회전 확인 → ③ AI 분석 → ④ 검수 → ⑤ 완료)가 지금 어디인지 항상 알려줍니다.

💡 AI가 시험지를 100% 완벽히 읽지는 못합니다. ④ 검수 단계가 품질을 좌우합니다 — 원본과 비교하며 천천히 봐주세요. 한 학교씩 차례대로 진행합니다.

1. 로그인 · 작업 화면(매트릭스)

  • 주소로 접속해 구글 계정으로 로그인합니다. (권한이 없다면 관리자에게 등록을 요청하세요.)
  • 로그인하면 작업 화면(매트릭스)이 나옵니다. 위쪽에서 연도와 과목 탭을 먼저 고릅니다. (결과 파일 이름이 이걸로 정해집니다)
  • 아래 학교 목록의 각 줄을 클릭하면 단계 카드가 펼쳐집니다: PDF → HWPX 변환 → 한글완성본 → 타이퍼 양식 → 해설
  • 줄 오른쪽 상태: 변환 중 / 변환완료 / 🔴 확인 필요 / 오류

2. 변환 시작 — 업로드와 회전 확인

1
연도·과목을 고른 뒤, 학교 줄의 📄 변환 시작 을 누릅니다. 변환 화면으로 이동합니다. (위쪽에 2026_1_1_a_공수1_○○고 같은 배지가 보이면 정상 — 이 칸에 결과가 등록됩니다)
2
업로드: 점선 상자에 시험지 PDF를 끌어다 놓거나 클릭해서 선택합니다. 학교·코드는 자동으로 채워져 있고, 지역·과목·주제(범위)는 시험지 1페이지 상단 표에 인쇄될 값이니 아는 만큼 적어주세요. 변환 시작 →
3
회전 확인: 페이지 미리보기가 나옵니다. 누워 있는 페이지가 있으면 ↻ ↺ 로 제목이 위로 오게 돌립니다. (전체를 한 번에 돌리는 버튼도 있음) 다 맞으면 이 방향으로 분석 시작 →
⚠️ 회전은 자동이 아닙니다. 누운 페이지를 그대로 두면 AI가 글자를 못 읽어 문제가 통째로 빠집니다. 반드시 눈으로 확인 후 시작하세요.
4
AI 분석: 자동으로 진행됩니다. 쪽수에 따라 수십 초 ~ 수 분. 끝나면 검수 화면으로 넘어갑니다.
💡 분석은 비용이 드는 단계입니다. 같은 시험지를 불필요하게 여러 번 돌리지 마세요. 하루 사용 한도를 넘으면 "비용 한도 초과" 안내가 뜹니다 — 관리자에게 문의.

3. 검수하기 (가장 중요)

화면 보는 법

  • 왼쪽: AI가 읽은 문제 목록 — 번호·배점·발문·보기(①~⑤)를 직접 고칠 수 있습니다.
  • 오른쪽: 원본 페이지 — 그림을 드래그로 지정하는 곳입니다. (4장)
  • 원본 시험지(PDF)를 옆에 띄워 놓고 문제마다 대조하세요.

텍스트·수식 고치기

①
틀린 글자는 발문/보기 칸에서 바로 타이핑해 고칩니다. 저장 버튼 없이 즉시 반영됩니다.
②
수식은 $ ... $ 사이에 들어 있습니다 (예: $x^2+3x+2$). $ 기호는 지우지 말고 그 안의 내용만 고치세요. $ 밖은 일반 글자, $ 안은 수식으로 한글파일에 들어갑니다.
③
잘못 인식된 문제(문제가 아닌 안내문 등)는 카드 오른쪽 위 삭제 로 뺍니다.

보기 기호(ㄱㄴㄷㄹ / ㉠㉡㉢㉣) 확인

  • <보기> 상자 라벨은 항상 사전순(ㄱ→ㄴ→ㄷ→ㄹ→ㅁ, ㉠→㉡→㉢→㉣→㉤)입니다. 자동 교정이 들어가 있지만, 순서가 어긋나거나 같은 기호가 두 번 보이면 오독이니 직접 고쳐주세요.
  • 발문에 <보기> 상자 글자가 있고 그 영역을 그림으로 배정하면, 글자는 자동 제거되고 그림 상자가 대신 들어갑니다. (카드 아래 안내 문구가 알려줍니다)
⚠️ 검수 중 새로고침·뒤로가기 금지! 문제 수정과 그림 배정이 모두 사라집니다. 실수로 닫으려 하면 브라우저가 경고를 띄우지만, 확인을 누르면 정말 날아갑니다.

4. 그림 넣기 · 낙서 지우기 · AI 재작도

그림은 자동으로 안 들어갑니다. 오른쪽 패널에서 직접 지정한 것만 들어갑니다.

1
페이지 탭(1쪽, 2쪽…)에서 그림이 있는 쪽을 열고, 그림 영역을 마우스로 드래그(초록 네모) → ＋ 그림 추가(크롭). 여러 개 반복 가능합니다.
2
추가된 그림 카드에서 배정 문제를 반드시 선택합니다. 미배정(빨간 표시) 그림이 있으면 한글파일을 만들 수 없습니다.
3
종류를 고릅니다 — 그림(도형·그래프) / 📊 표(격자·실선 표). 표를 '그림'으로 두면 재작도 품질이 떨어집니다.
4
낙서 지우기: 학생 필기가 섞였으면 그림 위에서 지울 부분을 빨갛게 드래그 → 🧹 낙서 지우기. (브러시 크기 조절 가능, 잘못 칠했으면 초기화)
💡 낙서 지우기는 수십 초까지 걸릴 수 있습니다 — 고장이 아닙니다. 넓게 칠할수록 고품질 AI 복원으로 처리되어 더 오래 걸리고, 특히 서버 업데이트 직후 첫 사용은 AI 모델을 새로 불러오느라 1분 가까이 걸릴 수 있습니다(그 다음부터는 빨라집니다). 버튼을 여러 번 누르지 말고 완료될 때까지 기다려 주세요.
5
🎨 AI 재작도: 스캔 그림을 깨끗하게 다시 그립니다. 그림이 여러 개면 🎨 전체 AI 재작도 한 번으로 모두 처리. 재작도 후에는 원본↔재작도 비교가 자동으로 뜹니다 — 숫자·라벨(F/F′ 등)·식이 바뀌지 않았는지 꼭 비교하세요.
6
품질이 아쉬우면 🔁 Pro로 다시 생성 (고품질·비용↑). AI가 원본과 다르게 그렸다고 판단하면 자동 반려되고 원본이 유지됩니다 — 그땐 다시 시도하거나 '낙서 지우기'한 원본을 그대로 쓰면 됩니다.
💡 재작도는 필수가 아닙니다. 스캔이 깨끗하면 크롭한 원본 그대로 넣어도 됩니다.

5. 한글파일 생성 · 완료

1
검수가 끝나면 위쪽 한글파일(.hwpx) 생성 → 을 누릅니다.
2
완료 화면에서 결과 요약(문제 수·수식 변환·그림 삽입)을 확인하고 ⬇ 한글파일 다운로드. 파일은 구글 드라이브 (AKP/연도/과목 폴더)에도 자동 저장되고, 매트릭스 칸이 변환완료로 바뀝니다.
3
📋 매트릭스로 돌아가기 로 복귀합니다.
⚠️ 한글에서 꼭 열어 확인하세요. 단·페이지 배치와 수식 모양은 한글에서만 정확히 보입니다. 문제 간격·그림 위치가 이상하면 관리자에게 알려주세요.
💡 완료 화면을 닫기 전이라면 검수 화면으로는 못 돌아가지만, 새 변환 없이 다운로드는 매트릭스의 다운로드 버튼으로 언제든 가능합니다. (작업 파일은 3일 뒤 자동 삭제되지만 드라이브 저장본은 계속 남습니다)

6. 🔴 확인 필요 처리

AI가 한글 수식으로 못 바꾼 수식이 있으면, 그 자리는 문서에 【확인필요】 표시와 함께 원본 수식 코드가 그대로 들어갑니다. 이런 파일은 매트릭스에 🔴 확인 필요 배지가 뜹니다.

1
완료 화면 또는 매트릭스에서 🔴 확인 필요 를 확인합니다. (배지에 마우스를 올리면 몇 곳인지 나옵니다)
2
다운로드한 파일을 한글에서 열고 Ctrl+F 로 "확인필요"를 검색합니다. 표시된 자리마다 원본 시험지를 보고 수식을 직접 입력해 바로잡고, 【확인필요】 글자는 지웁니다.
3
다 채웠으면 매트릭스 학교 줄을 펼쳐 확인 완료 를 누릅니다. 배지가 사라지고 누가 확인했는지 기록됩니다.
⚠️ 배지를 무시하고 그대로 쓰면 수식 대신 영문 코드가 인쇄됩니다. 배지가 있는 파일은 반드시 채운 뒤 사용하세요. (배지가 없어도 한글에서 배치 확인은 항상 권장)

7. 완성본 올리기 (한글완성본 · 타이퍼 양식 · 해설)

변환 후의 마무리 산출물은 매트릭스 단계 카드에 직접 업로드해 보관합니다.

  • 학교 줄을 펼쳐 해당 단계 카드에서 업로드 — 파일을 선택하면 등록됩니다.
  • 이미 있으면 교체 / 다운로드 / 삭제.
  • 🔒 잠금으로 보이는 단계는 내 권한 밖입니다 — 필요하면 관리자에게 요청하세요.
  • 시험지를 다른 학교·과목 칸으로 옮기려면 PDF 카드의 이동 을 씁니다.

8. 자주 하는 실수 · 주의

검수하다 새로고침했더니 다 날아갔어요검수 화면의 수정·그림 배정은 저장 전(한글파일 생성 전)에는 브라우저에만 있습니다. 새로고침·뒤로가기 금지. 날아갔으면 처음부터 다시 변환해야 합니다.
그림 추가를 눌러도 안 돼요드래그로 영역(초록 네모)을 먼저 그려야 버튼이 켜집니다. 오류 알림이 뜨면 그 내용을 관리자에게 전달하세요.
"한글파일 생성"이 안 눌려요 / 경고가 떠요미배정 그림이 있어서입니다. 각 그림 카드에서 배정 문제를 선택하거나, 안 쓸 그림은 삭제하세요.
수식이 이상하게 나와요검수에서 $ ... $ 안 내용을 확인하세요. $ 기호를 지웠으면 수식이 일반 글자가 됩니다. 생성 후라면 6장(확인 필요)을 보세요.
보기 기호(ㄹ/ㅁ, ㉣/㉤)가 틀려요자동 교정이 있지만 완벽하진 않습니다. 검수에서 사전순(ㄱㄴㄷㄹㅁ / ㉠㉡㉢㉣㉤)에 맞게 직접 고쳐주세요.
다운로드 버튼이 없어졌어요작업 파일은 3일 뒤 자동 삭제됩니다. 그 후엔 구글 드라이브 AKP 폴더에서 받으세요. (드라이브엔 계속 남습니다)
"비용 한도 초과"가 떠요하루 AI 사용 한도에 도달했습니다. 내일 다시 하거나 관리자에게 문의하세요.
변환이 안 끝나요 / 오류가 떠요잠시 기다려도 그대로면 화면의 오류 메시지와 함께 관리자에게 알려주세요. 매트릭스에서 다시 변환으로 재시도할 수 있습니다.
잘못 변환했어요 / 지우고 싶어요매트릭스 학교 줄을 펼쳐 HWPX 카드의 삭제. 드라이브 저장본까지 함께 지워지니 신중히.
💡 막히면 언제든 관리자에게 물어보세요. 이 설명서는 위쪽 🖨 인쇄 로 종이로도 뽑을 수 있습니다.
