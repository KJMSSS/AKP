0. 30초 요약 · 핵심 철학

PDF 업로드 → (자동 OCR 변환) → 검수 보기에서 틀린 것만 고쳐 제출 → 검수본 HWPX 다운로드 │ (고친 "검수 전 → 수정 후"가 자동 기록) ↓ 관리자 화면 "반복 교정 분석"에서 반복 오류 확인 → 패턴 등록 한 번 ↓ 다음 변환부터 OCR이 같은 실수를 안 함 (자동 교정)
💡 핵심 철학 — 사람이 매번 고쳐주는 구조가 아니라, 한 번 고친 걸 패턴으로 만들어 OCR 자체를 좋게 만듭니다. 학원장 손은 "검수 한 화면"과 "가끔 패턴 승인"에만 둡니다.

1. 로그인 · 역할(권한)

  • 주소(akp-production.up.railway.app) 접속 → 구글 계정 로그인.
  • 새 직원은 관리자가 먼저 등록해야 들어올 수 있습니다(6-1).

역할과 볼 수 있는 단계

역할표시접근 STEP비고
tier1기본STEP 1~4PDF·검수·한글완성본
tier2그림완성STEP 1~4그림 검수 담당
tier3타이퍼STEP 1~5+ 타이퍼 양식

💡 역할은 STEP 카드 접근 범위를 정합니다. 비용 한도는 역할과 별개로 1인당 설정합니다(6-1).

2. 작업 화면(STEP 1~6) 읽는 법

위에서 연도 / 과목 탭을 고르면 그 과목의 학교 목록이 줄지어 나옵니다. 각 학교 줄은 STEP 1~6 카드로 진행 상태를 보여줍니다.

STEP이름의미버튼(예)
1PDF원본 시험지재업로드 · 이동
2HWPX 검수전변환 직후 초안다운로드 · 삭제
3HWPX 검수완검수 끝난 결과검수보기 · 다운로드
4한글완성본타이핑 마무리본업로드
5타이퍼 양식2단 타이퍼용자동 생성 · 업로드
6해설해설지업로드
  • 각 칸 배지(있음/완료/없음)로 어디까지 됐는지 봅니다.
  • 새 변환 시작 = STEP 1에 PDF 올리기, 품질 핵심 = STEP 3 검수보기.
  • 과목 탭에 학교가 없으면 학교 추가 / 일괄 추가(줄 단위 붙여넣기)로 넣습니다.

3. 변환하기 · 비용 · 무과금 재변환

1
연도·과목을 먼저 고릅니다 → 파일명이 [연도_학년_학기_a/b_과목약어_학교명] 규칙으로 정해집니다.
2
해당 학교 줄 STEP 1에 PDF 업로드(또는 끌어다 놓기).
3
정답·해설까지 포함하려면 정답/해설 포함 옵션을 켭니다(문제만이면 끔).
4
1~2분 후 STEP 2(검수전)가 있음이 되면 STEP 3 검수보기로.
💡 누운(회전된) 시험지는 자동으로 똑바로 돌려 처리하고, 보정본은 구글 드라이브 AKP 폴더에도 저장됩니다.
⚠️ 같은 PDF를 또 올리면 변환이 다시 돌아 비용이 또 듭니다. 한 번만. 잘못 올렸으면 STEP 2 삭제 후 다시.

3-1. 비용 한도

  • 1인당 일일 사용 한도(USD). 도달하면 변환이 막힙니다. 관리자는 무제한.

3-2. 무과금 재변환 (중요)

  • 변환 결과 OCR 인식 마크다운(.md)만 있으면 OCR을 다시 호출하지 않고(재과금 0) 한글 파일을 다시 만들 수 있습니다.
  • 화면의 OCR 기록(.md) 버튼으로 그 .md를 받아 둡니다(4장).

4. 검수 핵심 + OCR 기록(.md)

직원 단계별 설명(화면 보는 법, ✓정확/✎수정, 수식 버튼판, 🔴확인 필요)은 직원 설명서(/guide)에 그림과 함께 있습니다. 여기선 운영자가 알아야 할 핵심만:

  • 왼쪽 = 원본 이미지, 오른쪽 = OCR 문제 카드. 카드 수식은 실제 모양으로 렌더됩니다(한글로 열 필요 없음).
  • ✓ 정확 / ✎ 수정. 수정 시 편집 칸:
    • "올바른 내용" → 최종 한글 파일에 반영.
    • "오류 메모" → 기록용(본문 안 바뀜).
  • 수식은 타이핑 말고 기호 버튼판으로 + 미리보기 확인.
  • 맨 아래 검수 완료 → HWPX 재생성 → 검수본(STEP 3)이 재과금 0으로 생성.
💡 이제 메모를 안 적어도 고친 내용은 자동 기록됩니다(5장). "왜 틀렸는지" 설명이 필요할 때만 메모를 추가하세요.

OCR 기록(.md) = 재과금 0 베이스

변환이 끝나면 그 시험지의 OCR 인식 결과 전체가 .md로 저장됩니다. OCR 기록(.md) 버튼으로 받아 두면 언제든 무과금으로 다시 빌드/수정할 수 있습니다.

5. ★ 품질 개선 루프 (이 도구의 심장)

검수에서 고친 내용을 버리지 않고 OCR 개선에 재투입하는 자동 루프입니다.

검수에서 고쳐 제출 │ (바뀐 문제마다 "검수 전(원본) → 수정 후"가 자동 기록 — 메모 없어도) ▼ corrections.jsonl 에 누적 │ ▼ 관리자 화면 "🔁 반복 교정 분석" ├─ 메모를 남겼으면 → 메모로 묶음 (예: "집합기호 없음" ×3) └─ 메모 없이 고쳤으면 → 내용 변화로 묶음 (예: "f'(x) → (삭제)" ×3 · 시험지 2개) │ ▼ 반복 오류(2회 이상)에서 "패턴 등록" 클릭 prompt_patterns.json │ ▼ 다음 변환부터 OCR 시스템 프롬프트에 자동 주입 같은 학교/과목에서 같은 실수가 안 남

5-1. 자동으로 되는 것

  • 검수 제출 시: 내용이 실제로 바뀐 문제마다 검수 전 → 수정 후 전체가 자동 기록(직원이 메모를 안 적어도). 원본 OCR 텍스트도 보존되어 사라지지 않습니다.
  • 그래서 "메모만 봐야 하는" 한계가 없어졌습니다 — 실제 내용 변화 자체가 분석 대상입니다.

5-2. 관리자가 하는 일 (가끔, 1분)

1
/admin → "🔁 반복 교정 분석" 패널을 봅니다.
2
🔴 반복 오류 N종 에서 2회 이상, 특히 시험지 여러 개에 걸친 것을 찾습니다.
3
그 줄의 패턴 등록 클릭 → 모달에 원문/교정이 미리 채워져 있습니다.
4
적용 범위 선택 — 전역(모든 변환) / 학교(예: 상일여고) / 과목(예: 미적분).
5
등록 → 다음 변환부터 자동 주입되어 같은 실수를 막습니다.
⚠️ 패턴 승인은 관리자(학원장)만 합니다. 직원은 검수만 하면 결과가 자동으로 쌓입니다. 자동 적용이 아니라 "승인된 것만" 적용되는 게 안전장치입니다.

6. 관리자 화면 기능

6-1. 사용자 · 역할 · 한도

  • 사용자 추가: 이름 · 구글 이메일 · 일일 한도(USD, 0=무제한) · 역할.
  • 역할 변경: 사용자 줄의 드롭다운(기본/그림완성/타이퍼/해설/직원).
  • 한도 변경: 한도 값을 클릭해 인라인 수정.

6-2. 검수 수정 로그

  • 누가·언제·어느 시험지의·몇 번 문제를·무엇으로 고쳤는지 전체 기록 + 직원별 통계 + 필터.
  • 잘못 들어간 항목은 되돌리기(분석 제외).

6-3. 반복 교정 분석

  • 5장 루프를 보는 곳. 테마 칩(집합/루트/분수 등)과 반복 그룹(메모/내용).
  • 시험지 N개에서 배지가 붙으면 더 체계적 → 우선 패턴화. 그룹의 패턴 등록으로 바로 승인.

6-4. 프롬프트 교정 패턴

  • 승인 패턴 목록 — 활성/비활성 토글, 삭제. 활성만 다음 변환에 주입.
  • 기본 패턴 일괄 등록: 도형·관계 기호(∠ △ ∽ ≡), 선분/벡터, 평행/수직 등 검증된 패턴을 한 번에(멱등). 초기 품질용.
  • 중복 정리: 같은 잡·문제·메모·교정 중복 제거.

7. 그림 검수

그림이 있는 시험지는 학교 줄에 🖼 검수 N건 배지가 뜹니다.

1
배지 클릭 → 그림 검수 화면.
2
자동으로 잡은 빨간 박스가 맞으면 자동 선택.
3
틀리면 드래그로 영역 지정 → 수동 적용. 그림이 아니면 건너뛰기.
4
다 했으면 HWPX 반영 → 검수한 그림이 한글 파일에.

8. 운영 절대 규칙

  1. 학교 단위 순차 처리 — 여러 학교 동시 병렬 금지.
  2. 학원장 PDF 원본 = 진짜 정답 — OCR/LLM보다 원본 PDF 우선. 검수 시 항상 원본 대조.
  3. LLM은 패턴 발견기 — 자동 적용 금지. 승인된 패턴만 주입(temperature=0).
  4. 크롭 OCR 표준 순서 — 전체 OCR 후 공란 발견해 통째로 재빌드 금지. 문제 단위 크롭 → 보정 → 1회 빌드.
  5. 한 번에 최고 품질 — 중간 검수·재빌드 루프를 전제로 설계하지 않음. OCR 품질 자체가 전부.

9. 자주 묻는 것 · 문제 해결

메모만 적었는데 결과가 안 고쳐져요"오류 메모"는 기록용. 실제 수정은 "올바른 내용" 칸에서. (메모 없이 본문을 고쳐도 자동 기록은 됩니다.)
빨간 【★ 확인 필요】가 남아요OCR이 못 읽은 자리. 원본 보고 검수에서 채우세요. 안 채우면 한글 파일에 빨간 글자로 남습니다.
같은 오류가 계속 나요관리자 반복 교정 분석에서 그 오류를 패턴 등록. 다음 변환부터 안 납니다.
비용이 또 나갔어요같은 PDF를 또 올리면 재변환됩니다. OCR 기록(.md)으로 무과금 재빌드하세요.
직원이 로그인이 안 돼요관리자 화면에서 그 이메일을 사용자 추가해야 합니다.
변환이 안 끝나요 / 오류가 떠요화면의 오류 메시지와 함께 알려 주세요.
결과 한글 파일은 어디 있죠검수 완료 후 다운로드 링크, 또는 STEP 2/3의 다운로드. 구글 드라이브 AKP 폴더에도 자동 저장.
💡 이 설명서는 위쪽 🖨 인쇄로 종이로도 뽑을 수 있습니다.
