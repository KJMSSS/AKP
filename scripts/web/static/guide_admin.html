0. 관리자가 하는 일 (한눈에)

관리자(학원장)는 변환 작업 자체보다 직원과 비용을 관리합니다. 핵심은 세 가지입니다 — 직원 계정 등록, 직원별 AI 사용 한도 지정, 비용 지켜보기.

직원 등록 → 역할·한도 지정 → 직원이 로그인·변환 작업 → 오늘/누적 비용 확인 → 필요하면 한도 조정
💡 관리자 본인 작업은 어떤 한도에도 걸리지 않습니다. 한도는 직원 계정에만 적용됩니다 — 학원장이 급히 변환해야 할 때 막히는 일은 없습니다.

이 모든 것은 관리자 화면(/admin) 한 곳에서 이뤄집니다. 직원이 실제 변환을 어떻게 하는지는 직원용 설명서를 참고하세요.

1. 직원(사용자) 등록 · 관리

등록된 사람만 로그인해서 변환기를 쓸 수 있습니다. 새 직원은 관리자 화면 위쪽 「사용자 추가」에서 등록합니다.

1
이름과 이메일을 입력합니다. 이메일은 그 직원이 로그인에 쓸 구글 계정 주소와 정확히 같아야 합니다 (오타 하나면 로그인이 안 됩니다).
2
Claude 한도·Gemini 한도 (하루 상한, USD)와 역할을 정합니다. 비워도 기본값(Claude $5 / Gemini $3)이 들어갑니다. 사용자 추가
3
추가되면 아래 「등록된 사용자」 표에 나타납니다. 이후 관리는 모두 이 표에서 합니다.

표에서 할 수 있는 일

  • 역할 변경 — 역할 칸의 드롭다운으로 즉시 바뀝니다.
  • 한도 변경 — Claude/Gemini 한도 숫자를 클릭하면 그 자리에서 수정됩니다(3장 참고).
  • 비활성화 — 접근만 막습니다. 계정과 사용 기록은 남습니다. 잠시 쉬는 직원, 퇴사 예정자에게 적합합니다. 다시 활성화 가능.
  • 삭제 — 계정을 완전히 제거합니다.
  • 이메일 클릭 — 클립보드로 복사됩니다.
⚠️ 삭제는 되돌릴 수 없습니다. 단순히 로그인을 막고 싶은 것뿐이라면 삭제 대신 비활성화를 쓰세요. 삭제는 완전히 내보낼 때만.

2. 역할(권한 단계) 이해

역할은 그 직원이 매트릭스에서 어느 단계까지 손댈 수 있는지를 정합니다. 권한 밖 단계는 직원 화면에 🔒 잠금으로 보입니다.

역할접근 가능한 단계주 용도
기본PDF · HWPX 변환 · 검수 · 한글완성본변환·검수 담당
그림완성PDF · HWPX 변환 · 검수 · 한글완성본그림·재작도 마무리 담당
타이퍼위 전부 ＋ 타이퍼 양식타이핑 양식 업로드까지
해설위 전부 ＋ 타이퍼 양식 ＋ 해설해설 제작까지
직원모든 단계전 과정 담당(만능)
관리자모든 단계 ＋ 사용자·한도 관리학원장 본인
💡 기본과 그림완성은 현재 접근 단계가 같습니다 — 라벨로 담당(업무 구분)을 표시하는 용도입니다. 변환·검수만 맡길 직원에게 둘 중 아무거나 쓰면 됩니다.
⚠️ 역할 드롭다운에 관리자는 없습니다. 관리 권한 부여는 화면에서 안 되며 시스템 설정이 필요합니다 — 관리자 계정을 늘려야 하면 개발 담당(조인식)에게 요청하세요.

3. AI 사용 한도 관리 (Claude · Gemini)

직원마다 Claude 한도와 Gemini 한도를 따로 둡니다. AI 사용은 곧 API 비용이므로, 직원별로 하루 상한을 걸어 과다 지출을 막습니다.

두 한도가 나뉘는 이유

  • Claude 한도 → 분석·검증 작업에 적용 (시험지를 읽어 문제로 구조화).
  • Gemini 한도 → 그림 재작도 작업에 적용 (스캔 그림을 다시 그리기).

한쪽을 다 써도 다른 쪽 작업은 계속됩니다. 예: Gemini 한도만 소진 → 재작도는 잠기지만 분석·검수는 그대로 가능.

기본 동작

1
매일 자정(한국 시간)에 자동 초기화됩니다. 오늘 다 썼어도 날이 바뀌면 다시 0부터입니다.
2
0 = 무제한. 한도를 0으로 두면 그 직원의 해당 AI는 제한 없이 쓸 수 있습니다.
3
직원이 한도를 넘으면 그 작업이 잠기고 오늘 한도를 초과했습니다 — 관리자에게 상향 요청 안내가 뜹니다. 직원이 요청하면 관리자가 표에서 올려주면 됩니다.

한도 바꾸기

1
표에서 바꿀 직원의 Claude 한도 또는 Gemini 한도 숫자(점선 밑줄)를 클릭합니다.
2
숫자를 고치고 저장 (또는 Enter). 취소는 취소 또는 Esc. 바로 적용됩니다.
💡 처음엔 한도를 낮게(기본값 정도로) 시작하고, 직원이 부딪히면 그때 올리는 것을 권합니다. 신입이 실수로 같은 시험지를 여러 번 돌려 비용이 새는 것을 막아줍니다.
⚠️ 이전에 등록된 직원이 있다면, 그 계정의 옛 단일 한도가 지금은 Claude+Gemini 합산 기준으로 적용됩니다. 표에서 두 한도를 한 번씩 눌러 각각 정해주면, 그때부터 분리 적용됩니다.

4. 비용 읽는 법 (오늘 · 누적)

표의 각 직원 줄에서 지출을 바로 확인할 수 있습니다.

  • 한도 셀의 「오늘 $…」 — 그 AI(Claude 또는 Gemini)로 오늘 쓴 금액. 한도의 80%를 넘으면 주황, 한도에 도달하면 빨강으로 표시됩니다.
  • 오늘 열 — Claude+Gemini 합산 오늘 지출(자정 초기화).
  • 누적 열 — 최근 7일 누적 지출.
  • 관리자 줄의 한도 칸은 「면제」로 나옵니다(한도 없음).

Claude 와 Gemini 비용의 차이

Claude (분석·검증)실제 사용한 토큰만큼 정확히 정산됩니다. 표의 금액이 곧 실제 비용입니다.
Gemini (그림 재작도)이미지 장당 추정 단가로 잡습니다 (고품질 Pro 재작도가 더 비쌈). 추정이라 실제 청구서와 약간 차이날 수 있으니, 청구서와 대조해 단가를 조정해야 할 수 있습니다(개발 담당에게 문의).
💡 비용이 특정 직원에게 몰리면, 그 직원 교육이 필요하거나(불필요한 재작도·재분석 반복) 한도를 손볼 시점입니다. 오늘/누적을 주기적으로 훑어보세요.

5. 구글 드라이브 · 파일 보관 정책

  • 완성된 한글파일(.hwpx)은 구글 드라이브 AKP/연도/과목 폴더에 자동 저장됩니다 — 이것이 영구 보관본입니다.
  • 서버의 변환 작업 파일은 3일 뒤 자동 삭제됩니다(매트릭스에서 잡을 지우면 즉시). 드라이브 저장본은 계속 남습니다.
  • 즉, 3일이 지나 변환기 안 다운로드 버튼이 사라져도, 드라이브 AKP 폴더에서 언제든 받을 수 있습니다.
⚠️ 드라이브 업로드가 안 될 때(완료됐는데 드라이브에 안 보임): 드라이브 접근 자격은 학원 공용이라 관리자만 갱신할 수 있습니다. 관리자로 로그인한 상태에서 /auth/gdrive 로 접속해 드라이브 재인증을 한 번 해주세요. 그래도 안 되면 개발 담당에게 알려주세요(구글 클라우드 쪽 드라이브 연동 점검 필요).
💡 드라이브 저장본은 지우지 마세요 — 이것이 학원의 진짜 자산입니다. 매트릭스에서 HWPX를 삭제하면 드라이브 저장본까지 함께 지워지니 신중히.

6. 파일 이름 규칙 (자동 명명)

결과 파일 이름은 직접 정하지 않습니다. 매트릭스에서 고른 연도·학년·학기·중간/기말·과목·학교로 자동으로 만들어집니다.

연도_학년_학기_a(중간)/b(기말)_과목약어_학교명

예: 2025_1_1_b_공수1_경신여고 → 드라이브 파일명 [2025_1_1_b_공수1_경신여고].hwpx

💡 그래서 변환 시작 전에 매트릭스에서 연도·과목 탭을 정확히 고르는 것이 중요합니다. 칸을 잘못 고르면 엉뚱한 이름으로 저장됩니다. 직원 화면 상단의 배지 (2026_1_1_a_공수1_○○고)로 저장될 이름을 미리 확인할 수 있습니다.

7. 자주 묻는 질문 · 문제 대응

직원이 로그인이 안 된대요① 등록한 이메일이 그 직원의 구글 계정 주소와 정확히 같은지 확인(오타·다른 계정). ② 표에서 활성 상태인지 확인(비활성이면 활성화). ③ 그래도 안 되면 삭제 후 다시 등록.
직원이 "한도 초과"가 뜬대요어느 AI인지 확인 — Claude면 분석·검증, Gemini면 그림 재작도가 막힌 것입니다. 표에서 그 직원의 해당 한도를 클릭해 올려주거나, 자정(한국 시간)이 지나면 자동으로 풀립니다.
특정 직원만 타이퍼/해설 단계를 못 써요역할이 낮아서입니다. 타이퍼 양식은 '타이퍼' 이상, 해설은 '해설' 또는 '직원' 역할이 필요합니다. 표에서 역할을 올려주세요(2장).
Gemini 비용이 실제 청구서와 달라요Gemini는 장당 추정 단가라 정확하지 않습니다. 단가 조정이 필요하면 개발 담당에게 요청하세요(설정값 변경).
완료됐는데 드라이브에 안 올라가요관리자로 로그인해 /auth/gdrive 재인증(5장). 여전히 안 되면 개발 담당에게 — 구글 클라우드 드라이브 연동 점검이 필요할 수 있습니다.
직원을 실수로 삭제했어요되돌릴 수 없습니다. 같은 이메일로 다시 등록하세요 (한도·역할은 새로 지정). 로그인만 잠깐 막을 거면 다음부터는 비활성화를 쓰세요.
비용을 아예 안 걸고 싶어요그 직원의 한도를 0으로 두면 무제한입니다. 단, 무제한은 과다 지출 위험이 있으니 신뢰하는 직원에게만.
화면이 이상하거나 오류가 계속 나요오류 메시지를 캡처해 개발 담당(조인식)에게 전달하세요. 앱은 서버(Railway)에서 돌아가며, 수정·배포는 개발 쪽에서 진행합니다.
💡 직원이 실제 변환을 어떻게 하는지 궁금하면 위쪽 「직원용 설명서」를 보세요. 이 문서는 🖨 인쇄로 종이로도 뽑을 수 있습니다.
